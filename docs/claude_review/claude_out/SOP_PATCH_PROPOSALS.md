# SOP_PATCH_PROPOSALS — 얼룩 SOP에 덧붙일 짧은 문장 패치
**원칙:** 기존 `why_ko`/`fresh_path_ko`/`dried_path_ko`를 **전면 재작성하지 않음**. 오탈자·내부코드·누락 가드만 짧게 덧붙이거나 치환. 66개 전체가 아니라 우선순위 얼룩과 공통 라이브러리로 관리.
---
## A. 전역 치환 규칙 (66개 얼룩 원천에 일괄 적용)
| 원천 표기 | 점주용 평어 | 비고 |
|---|---|---|
| `Cap1` | 약하게(찍어 바름) | 힘 단계. 부피 아님. |
| `Cap2` | 중간(찍어 바름 반복) | 문지름 아님. |
| `Cap3` | 강하게(찍어 바름 여러 회) | 여전히 옆으로 문지름 금지. |
| `D2` | 주방세제 | 시판 마트, 주방 코너. |
| `E1` | 효소(액체 효소세제) | 시판 마트 세탁 코너. 성분표 "enzyme/effzyme/protease" 확인. |
| `E2` | 아밀라아제(전분 분해 효소) | 액체 효소세제 중 전분 표기 있는 제품. |
| `A3` | 흰 식초 1:4 | 5% 식용 식초 원액 기준. 예: 200ml 분무기 = 식초 40ml + 물 160ml. |
| `X2` | 옥살산 2% 수용액 | 약국·화공약품점. **장갑·마스크·즉시 중화 필수.** |
| `S1` | 워시프렌즈 중성세제 | 본사 공급. 시판 대체: 중성 손세탁세제(pH 중성 표기). |
**Cap 힘 개념 공통 문구(모든 SOP `fresh_path_ko` 서두 인접에 삽입):**
`※ 힘 단계 = 찍어 바름의 반복 횟수·압력. 어느 단계에서도 옆으로 문지르기 금지.`

## B. 공통 삽입 문장 라이브러리 (조건 만족 시 자동 삽입)
### B-1. 원단 안전 가드 (산소·효소·용제·염소·옥살산 사용 SOP 전부)
`※ 실크·울·가죽·아세테이트: 이 약품 금지. 워시프렌즈 중성세제(또는 시판 중성 손세탁세제) + 찬물만. 확신 없으면 전문 의뢰.`
### B-2. 수온 표준 명시 (수온 언급 SOP 전부)
- "찬물" → "찬물(15–20°C, 손 담그면 시원)"
- "미온" → "미온(30–35°C, 손 담그면 따끈)"
- "온수" → "온수(40–50°C, 손 담그면 뜨거움)"
- "고온" → "고온(60°C 이상, 원단 허용 최고온에서만)"
### B-3. 도구 이름 통일
- "연질 솔"·"부드러운 솔" → "부드러운 솔(아기 칫솔 또는 세탁 전용 부드러운 솔, 강모·철사·구두솔 금지)"
- "분무기" → "200ml 분무기(예: 식초 1:4 = 식초 40ml + 물 160ml)"
- "흰 천" → "흰 면 천 또는 키친타월(색 있는 천 금지 — 이염 위험)"
- "담금통" → "얕은 담금통(얼룩 부위만 잠기게, 옷 전체 침지 금지 — 이염 위험)"
### B-4. PPE 삽입 (해당 얼룩·약품 필요 시)
- 피·구토·분변·소변: `장갑 필수(니트릴). 마스크 권장. 청결물과 도구·통 분리.`
- 용제(아세톤·시너·미네랄스피릿) / 락스 / 염모제: `창문 열어 환기 필수. 밀폐 공간·화기 금지.`
- 옥살산: `장갑·마스크. 처리 후 즉시 베이킹소다 약희석으로 중화.`
- 마른 곰팡이·라테라이트 브러시: `실외·마스크. 포자·분진 흡입 금지.`
### B-5. 구석 테스트 표준 문장 (해당 5종 약품 사용 SOP 전부)
`※ 사용 전 눈에 안 띄는 밑단 안쪽에 1–2방울, 흰 면 천 눌러 30초. 색빠짐·번짐·손상 없으면 진행. 알코올·아세톤·용제·산소표백·옥살산은 이 테스트 없이 사용 금지.`
### B-6. 성공률·거절 3단 표준어 (모든 SOP 후미)
- 등급 1: `시도 가능 — 완전 제거는 보장 없음.`
- 등급 2: `부분 제거만 가능 — 잔색·잔영 남을 수 있음. 접수 시 동의 필수.`
- 등급 3: `복원 불가 — 접수 거절 또는 전문 의뢰 안내.`
### B-7. 혼합 금지 짧은 링크 (락스 사용 SOP 전부)
`※ 락스 + 식초/암모니아/산소표백제 절대 금지(유독 가스 또는 반응성 상실). 락스 사용 통·솔은 완전 헹군 뒤에만 다른 약품 접촉.`

## C. 우선순위 15개 얼룩 — 짧은 문장 패치
각 얼룩은 `+why`(왜 절에 덧붙일 한 줄) / `+fresh`(fresh_path에 덧붙일 한 줄) / `+dried`(dried_path에 덧붙일 한 줄) 형식. 나머지는 A·B 규칙으로 자동 적용.
### C-1. S_BLOOD_FRESH [L1]
- `+fresh`: `※ 실크·울: 효소 금지 → 워시프렌즈 중성세제·찬물만. 세게 문지르기·온수·건조기 절대 금지(단백질 갈색 영구 고착).`
### C-2. S_BLOOD_DRY [L2]
- `+dried`: `등급 2 부분 제거 우선. 갈색 잔영 가능 사전 동의. 흰 면만 3% 과산화수소(약국 창상소독액) 10분, 구석 테스트.`
### C-3. S_BLACK_COFFEE [L1]
- `+fresh`: `※ 실크·울: 산소 금지. 흰 식초 약하게(1:8) + 워시프렌즈 중성세제·찬물만.`
- `+dried`: `건조 후 성공률 급감 — 접수 시 등급 2 부분 제거 고지.`
### C-4. S_MILK_COFFEE [L2]
- `+fresh`: `순서 절대: 단백질·지방(효소 또는 주방세제) 먼저 → 흰 식초 1:4 나중. 순서 바꾸면 색소 영구 고착.`
### C-5. S_RED_WINE [L1]
- `+fresh`: `유색: 산소 원칙 금지 → 흰 식초 1:4 반복만. 흰 면만 산소 15–45분, 구석 테스트 통과 시.`
- `+dried`: `등급 2 부분 제거. 적자색 잔영 사전 동의.`
### C-6. S_KIMCHI [L2]
- `+fresh`: `유색: 산소 원칙 금지 — 고춧가루 색소가 빠질 때 원단 색도 동반 손실. 흰옷만 산소, 구석 테스트 통과 시.`
- `+fresh`: `도포 순서: 주방세제 찍어 바름 → 30초 대기 → 부드러운 솔 가볍게 → 즉시 헹굼.`
### C-7. S_FISH_SAUCE(느억맘) [L2·VN]
- `+fresh`: `냄새 잔존 등급 2 사전 고지. 실크·울: 효소 금지 → 워시프렌즈 중성세제·찬물+짧은 흰 식초 1:8만.`
### C-8. S_COOKING_OIL / S_MOTORBIKE_OIL / S_ENGINE_OIL [L1/L2/L3]
- `+fresh` 공통: `미끄럼(만졌을 때 매끈함)·냄새 남은 채 건조 절대 금지 — 열고착 시 성공률 급감.`
- `S_MOTORBIKE_OIL +fresh` 추가: `※ 용제 사용 시 환기 필수·화기 금지. 실크·울에 강한 용제·고온 절대 금지.`
- `S_ENGINE_OIL +dried`: `등급 2 부분 제거 또는 등급 3 복원 불가 사전 판단 — 실크·울 흡수 시 즉시 전문 의뢰.`
### C-9. S_LIPSTICK [L2]
- `+fresh`: `3층 순서: (a) 겉 왁스 부드러운 솔로 약하게 → (b) 안쪽에서 70% 이소프로판올 찍어 바름, 매번 새 흰 면 천, 3–5회 → (c) 남은 색은 주방세제 45°. 옆 문지름 절대 금지.`
### C-10. S_INK_PEN [L1]
- `+fresh`: `알코올은 반드시 70% 이소프로판올(약국 소독용). 무수 알코올·에탄올 95%·메탄올 금지.`
- `+dried`: `이미 다림질·건조기 통과 시 등급 3 복원 불가 우선 검토.`
### C-11. S_INK_PERMANENT (유성매직) [L3]
- `+why`: `실크·울·아세테이트·프린트 원단: 접수 시 등급 3 복원 불가 또는 전문 의뢰 우선.`
### C-12. S_LATERITE(라테라이트·적토) [L3·VN]
- `+fresh`: `옥살산 2% 수용액: 15분부터 시작, 최대 30분 상한. 즉시 헹굼 + 베이킹소다 약희석 중화(중화 없이 방치 시 셀룰로스 손상 누적). 락스 절대 금지(철 영구 고착).`
- `+dried`: `이미 세탁·건조 후: 등급 3 복원 불가에 가까움 — 사전 고지.`
### C-13. S_SHIRT_YELLOW / S_SWEAT_YELLOW [L2]
- `+fresh` 공통: `락스 절대 금지 — 단백질 황변에 락스는 더 누렇게 만들고 영구화. 순서: 효소 먼저 → 흰옷만 산소 침지.`
### C-14. S_URINE / S_VOMIT / S_FECES [L1→L3 위생]
- `+fresh` 공통: `장갑 필수. 청결물과 도구·통 분리. 온수·건조기 절대 금지(단백질 고착). 암모니아·염소 함유 세정제 혼합 절대 금지.`
### C-15. S_MILDEW(곰팡이) [L2/L3]
- `+fresh`: `실외 작업·마스크. 마른 포자 털기 시 흡입 금지. 흰 식초와 락스 절대 혼합 금지(염소 가스). 가죽·실크·울·심함은 전문 의뢰.`
### C-16. S_DYE_TRANSFER(이염) [L2]
- `+fresh`: `건조기 통과 후에는 등급 3 복원 불가 우선. "안전 조건 락스" = 흰 100% 면·폴리 단독, 스판덱스 혼방 금지, 5–10분 상한, 즉시 완전 헹굼.`
### C-17. S_GLUE(접착제) [L3]
- `+dried`: `502(시아노아크릴레이트) 굳음: 접수 시 등급 3 복원 불가 우선 검토 → 전문 의뢰 또는 반려.`
### C-18. S_PAINT_OIL(유성페인트) [L3]
- `+dried`: `아세테이트·실크·울: 시너 사용 금지 → 즉시 전문 의뢰. 그 외 원단도 등급 2 부분 제거 우선.`
