# L1_REWRITE_SAMPLES — 대표 5얼룩 지시 톤 샘플
**톤 규칙:**
- 명령형 짧은 문장. "~하세요"·"~마세요" 중심.
- 각 단계 앞에 번호. 각 단계마다 도구·시간·수온 숫자로 명시.
- 매 답 서두: 원단·색상·신선/마름 확인 → 실크·울·가죽·아세테이트면 후퇴 문구 우선.
- 매 답 말미: 건조 전 강광 확인 → 등급 고지.
- 옆으로 문지름 금지 반복. 힘 단계(약하게/중간/강하게)는 "찍어 바름"의 반복 횟수·압력을 뜻함.
**공통 도구 약어(라이브 답에서 그대로 사용):**
- 흰 면 천 = 흰 면 천 또는 키친타월(색 있는 천 금지)
- 분무기 = 200ml 분무기
- 부드러운 솔 = 아기 칫솔 또는 세탁 전용 부드러운 솔
- 담금통 = 얕은 담금통(얼룩 부위만 잠기게)
- 타이머 = 주방 타이머 또는 스마트폰
---
## 1) 피 (신선) — [L1 초보 단독]
**확인 먼저**
- 얼룩이 아직 축축한가요? → 이 SOP 진행.
- 이미 말랐거나 이미 온수 세탁을 지났다면 → 마른 피 SOP로 이동, 등급 2 고지.
- 원단이 실크·울·가죽인가요? → **효소 금지. 아래 (5)단계 건너뛰기. 워시프렌즈 중성세제만.**
**도구 준비**
- 니트릴 장갑 끼세요.
- 흰 면 천 3장, 담금통, 소금(주방용), 액체 효소세제, 타이머.
**단계**
1. **옷을 뒤집으세요.** 얼룩이 원단 안쪽에 오게 하세요.
2. 수도꼭지에서 **찬물(15–20°C, 손 담그면 시원)** 을 트세요. 안쪽 얼룩 부위에 **2–3분간 흘려 헹구세요.** 물이 맑아질 때까지.
3. **온수 절대 금지.** 온수는 피를 익혀서 갈색으로 영구 고정합니다.
4. 담금통에 **찬물 1L + 소금 큰술 2**를 넣으세요. 얼룩 부위만 담그세요. **타이머 15분.** 15분 지나면 꺼내세요.
5. 얼룩이 남았으면 **액체 효소세제 큰술 1을 얼룩에 직접 바르세요.** 15분 대기. **※ 실크·울은 이 단계 건너뛰기 — 워시프렌즈 중성세제로만 문지르지 말고 찍어 바르세요.**
6. **찬물로 세탁.** 온수 절대 금지.
7. **건조 전 강광 확인.** 밝은 조명 아래에서 얼룩 흔적 확인. **잔색·갈색 있으면 건조기·다림질·햇빛 금지 → (4)단계로 돌아가 반복.**
8. 완전히 사라졌으면 통풍 건조.
**절대 하지 말 것**
- 세게 문지르지 마세요. 흡수·찍어 바름만.
- 온수·건조기·다림질을 잔색 상태에서 사용하지 마세요. **한 번이라도 열이 닿으면 영구 고착됩니다.**
**등급 고지**
- 신선한 피 = 등급 1 시도. "완전 제거는 보장드리기 어렵습니다."
- 이미 온수·건조기 지난 피 = 등급 2 부분 제거 재접수.

## 2) 블랙커피 (신선, 우유 없음) — [L1 초보 단독]
**확인 먼저**
- 우유·라떼가 섞였나요? → **밀크커피 SOP로 이동**(순서가 다릅니다).
- 원단이 실크·울인가요? → **산소표백 금지. 아래 (5)단계 건너뛰기. 흰 식초는 1:8로 더 묽게.**
- 흰옷인가요, 유색인가요? 색을 기억하세요 — (5)단계에서 결정.
**도구 준비**
- 흰 면 천 3장, 200ml 분무기, 담금통, 5% 흰 식초, 산소표백제(과탄산나트륨 분말), 타이머.
- **분무기 준비: 식초 40ml + 물 160ml.** 흔들어 섞으세요.
**단계**
1. **옷을 뒤집으세요.** 얼룩이 안쪽에 오게.
2. **찬물(15–20°C)** 을 흘려 얼룩 뒷면에 부으세요. 흰 면 천을 얼룩 위에 얹어 **수직으로 눌러 흡수하세요.** 매번 깨끗한 면으로 바꾸세요. **옆으로 문지르지 마세요.**
3. 분무기를 흔들어 얼룩에 **가볍게 3–4번 분무하세요.** 흰 면 천으로 다시 눌러 흡수. **타이머 5분.**
4. 5분 지나면 찬물로 헹구세요. 얼룩이 옅어졌는지 밝은 조명에서 확인.
5. **잔색이 남았고 흰옷·색 안정 유색이면**: 담금통에 **미온(30–35°C) 1L + 과탄산나트륨 큰술 1**을 풀고 얼룩 부위만 담그세요. **타이머 15–30분.** ⚠️ **구석 테스트 먼저**: 안 보이는 밑단에 1–2방울 발라 30초 대기 → 색빠짐 없으면 진행. **색 미확인·실크·울·나일론·스판덱스는 이 단계 생략.**
6. **미온(30–35°C) 세탁.**
7. **건조 전 강광 확인.** 잔색 있으면 (3)단계 반복. 확실히 사라지기 전에는 건조기·다림질 금지.
**절대 하지 말 것**
- 뜨거운 물로 헹구지 마세요. 색소 고착.
- 산소표백제와 락스를 같이 쓰지 마세요.
- 잔색 있는 채 건조하지 마세요.
**등급 고지**
- 신선·즉시 처리 = 등급 1 시도.
- 이미 건조기 지난 커피 = 등급 2 부분 제거.

## 3) 식용유 (신선) — [L1 초보 단독]
**확인 먼저**
- 오토바이 오일·엔진오일이 아닌가요? → 검은색·냄새 강함·미끄러움 심함이면 **오토바이 오일 SOP로 이동**(L3, 감독 필요).
- 원단이 실크·울인가요? → **온수 금지. 리파아제 신중. 워시프렌즈 중성세제 위주.**
**도구 준비**
- 옥수수전분 또는 밀가루(주방용 아무 흰 가루 OK), 주방세제, 흰 면 천, 부드러운 솔, 타이머.
**단계**
1. **키친타월로 여분 기름을 눌러 흡수하세요.** 옆으로 문지르지 마세요.
2. 얼룩 위에 **옥수수전분(또는 밀가루)을 두껍게 덮으세요.** 얼룩이 안 보일 만큼. **타이머 10–30분.**
3. 시간 지나면 **손이나 부드러운 솔로 가루를 털어내세요.** 기름을 흡수한 가루가 떨어져 나옵니다. 필요하면 새 가루로 한 번 더 반복.
4. **미온(30–35°C) 물에 주방세제 1–2방울을 얼룩에 직접 바르세요.** 부드러운 솔로 **약하게 원을 그리며 5–10분.** 세게 문지르지 마세요.
5. 미온 물로 헹구세요.
6. **미끄러움을 손끝으로 확인하세요.** 아직 매끈하면 (4)단계 반복.
7. 미끄러움 사라졌으면 세탁. **미끄러움 남은 상태에서 건조기 절대 금지 — 열고착됩니다.**
**절대 하지 말 것**
- 물 먼저 부어 문지르지 마세요. 기름이 물에 안 녹고 섬유로 더 들어갑니다.
- 뜨거운 물로 헹구지 마세요(기름 남으면 고착).
- 미끄러움 확인 없이 건조기·다림질 금지.
**등급 고지**
- 신선·즉시 = 등급 1 시도.
- 이미 건조기 지난 식용유 = 등급 2 부분 제거.

## 4) 볼펜잉크 (신선) — [L1 초보 단독, 주의]
**확인 먼저**
- 유성매직·영구 잉크가 아닌가요? → 마르면 광택이 남고 손톱으로 안 지워지면 유성 → **L3, 전문 의뢰 우선.**
- 원단이 실크·울·아세테이트·프린트 티셔츠인가요? → **알코올 금지. 즉시 상급 확인.**
**도구 준비**
- **70% 이소프로판올(약국 소독용 알코올).** 무수 알코올·에탄올 95%·메탄올 금지.
- 흰 면 천 5장 이상(자주 교체합니다), 흡수지(키친타월 여러 장), 타이머.
- **환기: 창문 열기.**
**단계**
1. **구석 테스트 먼저.** 옷 안쪽 밑단에 알코올 1–2방울 → 흰 면 천 눌러 30초 → 색빠짐·번짐 없으면 진행. 색빠짐 있으면 즉시 중단.
2. 얼룩 아래에 **흡수지 3–4장을 겹쳐 깔아주세요.** 알코올·잉크가 아래 종이로 빠져나갑니다.
3. **옷을 뒤집어 얼룩을 안쪽으로.** 알코올을 흰 면 천에 살짝 묻히세요(직접 옷에 붓지 마세요).
4. **얼룩 위에 수직으로 눌러 3초 → 떼세요.** 옆으로 문지르면 잉크가 번집니다. **매번 깨끗한 흰 면으로 교체.** 아래 흡수지도 잉크가 묻으면 새 종이로 교체.
5. **5–10회 반복.** 잉크가 흰 면과 흡수지로 계속 옮겨져야 합니다.
6. 잉크가 눈으로 안 보일 때까지 (3)–(5) 반복. 찬물로 헹구세요.
7. **찬물 세탁.**
8. **건조 전 강광 확인.** 잔색 있으면 (3)–(5) 반복. 다림질·건조기 금지 — 열 고착.
**절대 하지 말 것**
- 옆으로 문지르지 마세요. 잉크가 사방으로 번집니다.
- 옷에 알코올을 직접 붓지 마세요. 색소가 원단 결을 따라 퍼집니다.
- 흡수지·흰 면을 재사용하지 마세요. 잉크가 다시 옷으로 옮겨갑니다.
- 잔색 상태에서 건조·다림질 금지.
**등급 고지**
- 신선한 볼펜 = 등급 1 시도. "완전 제거는 보장드리기 어렵습니다."
- 이미 세탁·건조 지난 볼펜 = 등급 2 부분 제거.

## 5) 진흙 (마름 기본 원칙) — [L1 초보 단독]
**확인 먼저**
- 붉은 적토(라테라이트)인가요? → 진흙 SOP 금지. **라테라이트 SOP(L3)로 이동.**
- 아직 젖었나요? → **먼저 말리세요. 젖은 채 문지르면 심부로 침투합니다.**
**도구 준비**
- 부드러운 솔(아기 칫솔 또는 세탁 전용 부드러운 솔), 흰 식초, 200ml 분무기, 타이머.
- **분무기 준비: 식초 40ml + 물 160ml.**
**단계**
1. **완전히 말리세요.** 실내 통풍 또는 햇빛(색 있는 옷은 그늘). 마르면 흙이 부서집니다.
2. 마르면 **옷을 실외에서 털어주세요.** 대부분의 흙이 떨어져 나갑니다.
3. **부드러운 솔로 얼룩 부위를 가볍게 쓸어주세요.** 원단 결 방향으로. 세게 문지르지 마세요.
4. 잔여 흙이 있으면 **찬물로 헹구세요.**
5. 일반 세제로 세탁.
6. **세탁 후에도 옅은 흙색이 남으면**: 분무기로 흰 식초 1:4를 얼룩에 분무 → **타이머 10분** → 헹궈 재세탁.
7. **건조 전 강광 확인.** 잔색 있으면 (6)단계 반복.
**절대 하지 말 것**
- 젖은 진흙을 문지르지 마세요. 흙 입자가 섬유 사이로 파고들어 세탁으로 안 빠집니다.
- 락스 사용하지 마세요. 흙에 철분이 있으면 락스로 인해 붉은 얼룩이 영구 고정될 수 있습니다.
- 붉은 적토를 이 SOP로 처리하지 마세요. **라테라이트는 별도 경로(L3).**
**등급 고지**
- 일반 진흙 = 등급 1 시도.
- 라테라이트·이미 세탁 후 잔색 = 등급 2 부분 제거.

## 라이브 답 톤 체크리스트 (Zalo 답 발송 전)
- [ ] 서두에 "확인 먼저" 3–4줄로 실크·울·가죽·신선/마름·유사 얼룩 분기 확인.
- [ ] 도구는 "이름 + 준비법(예: 분무기 = 식초 40ml + 물 160ml)".
- [ ] 각 단계에 시간·수온 숫자.
- [ ] 힘 단계는 "약하게 / 중간 / 강하게(찍어 바름)"만. 옆으로 문지름 금지 반복.
- [ ] 구석 테스트가 필요한 약품(알코올·아세톤·용제·산소표백·옥살산) 사용 시 그 단계 앞에 30초 테스트 문장.
- [ ] "절대 하지 말 것" 블록 3–5개 항목.
- [ ] "건조 전 강광 확인" 반드시 포함.
- [ ] "등급 고지" 등급 1·2·3 중 하나 명시.
