# CURRICULUM — Wash Friends 점주 세탁 교육 L1·L2·L3
**대상:** 베트남 현지 가맹 점주. **채널:** Zalo OA (본사 공식) 짧은 답 + 주간 교육 챕터.
**원칙:** 매 챕터에 [L1/L2/L3] 태그. 반복 금지 — 상위 레벨은 하위 완료 전제. 실크·울·가죽·아세테이트는 어떤 레벨에서도 후퇴가 정답.
---
## L1 — 초급 (매일 학습 · Zalo 짧은 답)
### L1-A. 기초 10가지 (얼룩 묻기 전 필수)
1. **[L1] 섬유 라벨 30초 판독** — 삼각형(표백)·원(드라이만)·손세탁 표시 3개 우선. 광택+얇음+미끈 = 실크·아세테이트 의심 → 강한 약품 전체 보류.
2. **[L1] 물 온도 4단계** — 찬물 15–20°C / 미온 30–35°C / 온수 40–50°C / 고온 60°C+. 단백질 얼룩(피·계란·우유·땀·구토·분변·소변)은 무조건 찬물. 의심되면 찬물부터.
3. **[L1] 문지름 금지 · 찍어 바름(블롯) 표준** — 흰 면 천을 얼룩 위에 얹어 수직으로 눌러 흡수, 매번 새 면. 옆으로 문지르면 색소·오일이 섬유 깊이 침투. 색소 계열은 처음 3분간 찍어 바름만.
4. **[L1] 건조 전 강광 확인 습관** — 밝은 조명(자연광 또는 백색 LED) 아래에서 잔색·기름 미끄럼·냄새 확인. 하나라도 있으면 열 처리(건조기·다림질·햇빛) 절대 금지. 열 = 얼룩 영구 고착.
5. **[L1] 구석 테스트 30초** — 밑단 안쪽·안감·솔기 여분에 약품 1–2방울, 흰 면 천 눌러 30초. 색빠짐·번짐·손상 없으면 진행. 알코올·아세톤·용제·산소표백·옥살산 5종은 구석 테스트 없이 절대 사용 금지.
6. **[L1] 절대 혼합 금지 3쌍** — 식초+락스 = 염소 가스 / 암모니아+락스 = 클로라민 가스 / 산소표백제+락스 = 반응성 상실. 잔여 성분도 위험 — 락스 사용 통·솔은 완전 헹군 뒤에만 다른 약품 접촉.
7. **[L1] 개인 보호구(PPE) 3종** — 니트릴 장갑(피·구토·분변·용제·옥살산·락스) / 마스크(포자·먼지) / 환기(용제·락스·염모제 필수, 밀폐 공간 금지).
8. **[L1→L3 거절 게이트] 초보 단독 금지 6조합 → 접수 시 100% 불가 고지 후 진행 또는 거절** — (a) 실크·울·가죽·아세테이트의 유성 페인트/유성 매직/시아노 접착제(502) (b) 건조기 통과 후 이염 (c) 원단 두께 침투한 오래된 곰팡이 (d) 성분 미상 화학 얼룩 (e) 실크·울에 흡수된 엔진오일·타르 (f) 가죽·스웨이드·모피의 유기용제 필요 얼룩.
9. **[L1] 도구 5종 표준** — 흰 면 천/키친타월(색 있는 천 금지) / 200ml 분무기 / 부드러운 솔 = 아기 칫솔 또는 세탁 전용 부드러운 솔(강모·철사·구두솔 금지) / 얕은 담금통(얼룩 부위만 잠기게) / 주방 타이머(눈짐작 금지).
10. **[L1→L2 진입] 약품 4대 그룹과 금지 원단** — 효소(실크·울 절대 금지, 40°C 초과 시 효소 실활) / 산소표백(흰 면·폴리·안정 유색만, 색 미확인·실크·울·가죽·나일론·스판덱스 금지) / 염소표백(흰 면·폴리만, 유색·실크·울·나일론·스판덱스·아세테이트·데오·황변·분유 금지) / 유기용제(아세테이트·레이온·비닐코팅 절대 금지, 구석 테스트·환기 필수).
### L1-B. 대표 5얼룩 — 초급이 매일 처리해야 하는 최소 세트
- **피(신선)** — 안쪽 뒤집어 찬물 2–3분 헹굼 → 소금물(찬물 1L + 소금 큰술 2) 15–30분 → 효소 15분(실크·울 금지) → 찬물 세탁 → 강광 확인. **온수·건조기 절대 금지(단백질 갈색 영구 고착).** 세게 문지르지 말 것.
- **블랙커피(신선)** — 안쪽 찬물 흡수(찍어 바름만) → 흰 식초 1:4(200ml 분무기 = 식초 40ml + 물 160ml) 5–10분 → 흰 면만 산소표백 15–30분(구석 테스트) → 미온 세탁 → 강광. **실크·울에 산소 금지.**
- **식용유(신선)** — 옥수수전분 또는 밀가루 10–30분 덮고 털기 → 주방세제 1–2방울 미온(30–35°C) 5–10분, 부드러운 솔 가볍게 → 헹굼 → 세탁 → **미끄럼 없어진 뒤에만 건조.**
- **볼펜잉크(신선)** — 70% 이소프로판올(약국 소독용) 구석 테스트 → 얼룩 아래 흡수지 → 안쪽에서 알코올 찍어 수직 블롯, **매번 새 흰 천** → 잉크 없어질 때까지 → 찬물 세탁 → 강광. **문지름 절대 금지(번짐).**
- **진흙(마름)** — 완전 건조 → 실외 털기·부드러운 솔 → 세제 세탁 → 잔색 있으면 흰 식초 1:4 → 강광. **젖은 채 문지르지 말 것(심부 침투).** 붉은 적토(라테라이트)는 이 경로 아님 — 별도 L3 경로.
### L1-C. 접수 3분 스크립트
1. 얼룩 종류·언제·이미 세탁했는지 확인.
2. 원단·색상 확인(라벨 또는 촉감).
3. 성공률 3단 고지 — "시도 / 부분 제거 / 복원 불가" 중 하나 선택 후 사진 동의.
4. 실크·울·가죽·아세테이트는 무조건 접수 담당자 상급 확인.
### L1-D. 거절 3단 문구
- 등급 1 시도: "저희가 시도해 볼 수 있습니다. 완전 제거는 보장드리기 어렵습니다."
- 등급 2 부분 제거: "완전 제거는 어렵고 잔색·잔영이 남을 수 있습니다. 그래도 진행하시겠어요?"
- 등급 3 복원 불가: "이 얼룩은 저희 매장에서 안전하게 처리하기 어렵습니다. 전문 의뢰 안내드릴게요."

## L2 — 중급 (주간 심화)
### L2-A. 원단×색×신선/마름 교차 판단
| 원단 | 흰색 신선 | 흰색 마름 | 유색 신선 | 유색 마름 |
|---|---|---|---|---|
| **면·린넨** | 전 약품 가능 (구석 테스트) | 산소 장침지·효소 밤새 가능 | 산소 신중(테스트) | 산소 원칙 금지, 식초 반복 |
| **폴리에스터·혼방** | 산소 OK, 60°C 상한 | 온수 세탁 가능 | 산소 조건부(테스트) | 식초·주방세제 위주 |
| **실크·울** | **효소·산소·염소·용제·옥살산 금지.** 워시프렌즈 중성세제 + 찬물만. | 좌동 + 전문 의뢰 우선 | 좌동 | 좌동 |
| **가죽·스웨이드·아세테이트** | 물 침지 자체 금지 → 전용 케어 또는 전문 의뢰 | 좌동 | 좌동 | 좌동 |
### L2-B. 3계열 세트 훈련
- **탄닌 세트(커피·차·와인·주스·간장·빈랑·사탕수수즙·화이트와인)** — 즉시 찬물 → 흰 식초 1:4 → 흰 면만 산소표백. 이른 열은 색소 고착. 실크·울에 산소 금지.
- **단백질 세트(피·계란·우유·땀·구토·분변·소변·모유)** — 찬물만(온수 금지) → 효소(실크·울 금지 → 워시프렌즈 중성세제) → 찬물·미온 세탁. 열 = 갈색 영구.
- **오일-지방 세트(식용유·버터·마요·엔진오일·오토바이 오일·타르·그리즈·립스틱·선크림)** — 흡착분(전분·밀가루) → 주방세제 → 필요 시 리파아제(액체 효소세제) → 미끄럼 없앤 뒤에만 건조. 열고착 시 성공률 급감. 실크·울에 강한 용제·고온 금지.
### L2-C. 색소·염료 계열 (립스틱·잉크·염모제·마스카라·구두약)
공통 원리: (1) 안쪽에서 (2) 흡수지를 밑에 깔고 (3) 알코올 또는 아세톤 찍어 (4) 수직 블롯, 매번 새 천. 문지르면 원단 옆·아래로 확산. 아세테이트·레이온·비닐코팅은 아세톤 절대 금지(원단 녹음). 흰옷 잔색은 산소 마무리.
### L2-D. 산소표백 결정 트리
1. 원단이 흰 면·폴리·색 안정 유색인가? 아니면 중단.
2. 구석 테스트 30초 통과? 아니면 중단.
3. 액체 3% 과산화수소(약국 창상소독액): 흰 면만 원액 5–10분 블롯.
4. 분말 과탄산나트륨(마트·워시프렌즈 공급): 미온 1L + 큰술 1(약 15g), 15분–2시간 상한.
5. 색 미확인·염소 이력·실크·울·가죽·나일론·스판덱스는 산소 자체 금지.
### L2-E. 이염(dye transfer) 대응
즉시 세탁기에서 분리, **건조 금지**(열 고착). 흰 면·폴리 단독이면 산소 장침지(병 안내 최대, 종종 6–8시간)→재세탁. 유색·실크·울은 산소만·테스트만·염소 금지·전문 고려. 이미 건조기 통과했으면 등급 3 복원 불가로 재분류.

## L3 — 고급 (월간·특수·거절)
### L3-A. 실패 후 2차·3차 순서
1차 실패 → 원단·잔여 얼룩 재판단 → **다른 계열 시도**(예: 탄닌 실패 시 색소 계열 아닌지) → 2차 실패 시 등급 2 부분 제거 재고지 → 잔여 수용 또는 전문 의뢰.
- 락스는 실패 얼룩 만능 해결책 아님 — 특히 데오·황변·분유·이염·실크·울에는 상황 악화.
- 열(다림질·건조기)로 "감추기" 시도 금지 — 클레임 확대.
### L3-B. 특수 품목 5종
- **가죽·스웨이드·모피** — 물 침지 자체 금지. 전용 클리너·전문 의뢰. 오염 부위만 마른 부드러운 천으로 흡수, 이후 상급 판단.
- **다운(패딩)** — 국소 얼룩만 부분 처리(중성세제·미온). 전체 침수 세탁은 전용 세제·저속 헹굼·완전 건조 원칙, 뭉침 방지 두들김.
- **정장(울·모직 상하)** — 얼룩 부위만 워시프렌즈 중성세제·찬물·부드러운 솔 가볍게. 전체 세탁은 원칙 드라이클리닝.
- **기능성 의류(방수·다운·스포츠)** — 계면활성 표면 코팅 손상 위험. 유연제·산소·염소 금지. 전용 세제.
- **아기옷·유아복** — 락스·강한 향 금지. 산소·효소 헹굼 충분히. 햇빛 건조 OK(단, 잔색 없을 때).
### L3-C. 베트남 현장 세트
- **라테라이트(붉은 적토)** — 젖은 채 문지르기 절대 금지(번짐). 락스 절대 금지(철 영구 고착). 완전 건조 → 실외 마른 브러시(마스크) → 찬물 → 면·린넨·폴리만 옥살산 2% 수용액(장갑) 15분부터 시작, 최대 30분 → 즉시 헹굼+베이킹소다 약희석 중화 → 잔색은 흰 식초 후 산소(허용 원단만). 실크·울은 흰 식초 약하게만, 심하면 전문 의뢰.
- **오토바이 오일** — 흡착분(전분) 반복 → 탈지 용제(환기 필수, 화기 금지) → 주방세제 세탁 → 미끄럼 없어진 뒤에만 건조. 실크·울에 강한 용제·고온 금지.
- **느억맘(액젓)** — 찬물 → 효소 15–30분 → 흰 식초 1:4(냄새 중화) → 흰 면만 산소 → 충분 헹굼 세탁. 냄새 잔존 가능 고지.
- **김치국** — 고형·건더기 제거 → 안쪽 찬물 → 주방세제 1–2방울 찍어 바름 → 헹굼 → 흰 식초 1:4 5–10분 → **흰옷만 산소(유색은 산소 원칙 금지 — 고춧가루 색소 = 원단 색 동반 손실)** → 세탁. 잔색 채 건조 절대 금지.
- **습기 곰팡이** — 실외·PPE(장갑·마스크) → 마른 포자 털기(흡입 금지) → 흰 식초 침지 → 세탁+산소(허용 원단) → 흰 면만 희석 락스(식초와 혼합 절대 금지) → 햇빛·통풍. 가죽·실크·울·심함은 전문 의뢰.
### L3-D. 클레임·접수·배상 판단
- **접수 사진 필수** — 원단 라벨·얼룩 원상태·색상 근접 촬영 3장. 스마트폰 자연광 아래.
- **동의서 등급 2·3 필수** — 부분 제거·복원 불가 고지에 서명 또는 Zalo 문자 회신 저장.
- **배상 기준** — 원단·연식·구매가·과실 비율. 초보 매장은 상급 판단 전 배상 확약 금지.
