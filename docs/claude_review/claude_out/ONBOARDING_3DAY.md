# ONBOARDING_3DAY — 신입 점주 3일 온보딩 + 주간 퀴즈
**대상:** 세탁 경력 0–3개월 신입 점주·점원.
**목표:** Day 3 종료 시 대표 5얼룩을 감독 없이 재현. 등급 1·2·3 접수 스크립트를 KO/VI로 구두 재현. 거절 게이트 6조합 즉시 인식.
**전제:** 매일 오전 2시간 이론 + 오후 2시간 실기 + 저녁 20분 Zalo 퀴즈.
---
## Day 1 — 기초 원칙과 안전
### 오전 (이론 2시간)
1. **섬유 라벨 30초 판독** — 삼각형(표백)·원(드라이만)·손세탁 심볼 3개. 실제 라벨 20장 실물 훈련.
2. **수온 4단계** — 찬물·미온·온수·고온. 손등으로 감별 실습.
3. **문지름 금지 · 찍어 바름 표준** — 흰 면 천으로 수직 블롯 실습.
4. **건조 전 강광 확인 습관** — 왜 열이 얼룩을 영구 고정하는지 화학 설명 없이 사진 사례로.
5. **구석 테스트 30초** — 밑단·안감·솔기에서 어떻게 하는지 실물 실습.
6. **혼합 절대 금지 3쌍** — 락스+식초/암모니아/산소. 왜 위험한지 짧게(가스명만).
7. **PPE 3종** — 장갑·마스크·환기. 언제 쓰는지 사례별.
### 오후 (실기 2시간)
- 대표 3얼룩 실습: **피·블랙커피·식용유** (샘플 원단에 인공 얼룩 → SOP 따라 재현).
- 담당 교관이 옆에서 손가락으로 짚어 확인.
- 실습 후 완료 사진 3장(라벨·얼룩·전체) 촬영 훈련.
### 저녁 Zalo 퀴즈 (10문항)
- Day 1 퀴즈 (아래 §주간 퀴즈 초안 참조).
### Day 1 통과 기준
- 라벨 판독 20장 중 15장 정답.
- 수온 4단계 손 감별 오차 5°C 이내.
- 대표 3얼룩 실습 완료·강광 확인 습관 획득.
---
## Day 2 — 얼룩 처리·도구·조달
### 오전 (이론 2시간)
1. **약품 4대 그룹** — 효소·산소·염소·용제. 각 그룹의 금지 원단·금지 조합.
2. **도구 5종 표준** — 흰 면 천·분무기·부드러운 솔·담금통·타이머. 각 도구의 준비법·금지 사용.
3. **조달 카드 5종** — 액체 효소세제·산소표백제·흰 식초·70% 이소프로판올·옥살산. 각각 어디서 사는지·성분표 무엇을 확인하는지.
4. **얼룩 계열 3세트** — 탄닌·단백질·오일. 각 세트의 순서 원칙.
5. **레벨 태그(L1/L2/L3) 개념 도입** — STAIN_LEVEL_TAGS 표 배포·설명.
### 오후 (실기 2시간)
- 대표 2얼룩 추가 실습: **볼펜·진흙**.
- 볼펜: 알코올 구석 테스트 → 수직 블롯 5–10회 → 매번 새 천 훈련.
- 진흙: 완전 건조 → 실외 털기 → 부드러운 솔 훈련.
- 실습 후 흡수지·흰 면 교체 습관 확인.
### 저녁 Zalo 퀴즈 (10문항)
- Day 2 퀴즈.
### Day 2 통과 기준
- 대표 5얼룩 SOP를 순서·시간·수온까지 구두 재현.
- 조달 카드 5종 성분·구입처 정답률 80% 이상.

## Day 3 — 접수·거절·클레임 방어
### 오전 (이론 2시간)
1. **접수 3분 표준 절차** — 얼룩 → 원단 → 등급 → 사진 3장 → 동의.
2. **등급 1·2·3 스크립트** — KO/VI 각각 구두 암송.
3. **거절 게이트 6조합** — 실제 얼룩 사진 20장 중 게이트 조합 즉시 판별 훈련.
4. **자동 상향 규칙** — 실크·울·가죽·아세테이트, 건조기 후, 성분 미상 → 한 단계 상향.
5. **사진 3장 표준** — 라벨·얼룩·전체. 실습.
6. **동의 확보 형식** — 등급 2·3의 Zalo 문자·종이 서명.
7. **초보는 배상 확약 금지** — 매장 매니저에게만.
### 오후 (실기 2시간·롤플레이)
- **롤플레이 10건** — 교관이 고객 역할, 신입이 접수·등급 판정·스크립트·사진 촬영·동의 확보.
- 케이스에 반드시 포함: 거절 게이트 2건, 등급 2 얼룩 3건, 실크·울·가죽 1건, 성분 미상 1건.
- 각 롤플레이 후 즉시 피드백.
### 저녁 Zalo 퀴즈 (10문항)
- Day 3 퀴즈 (접수·거절 중심).
### Day 3 통과 기준
- 롤플레이 10건 중 8건 이상 등급 정확 판정 + 스크립트 정확 재현.
- 거절 게이트 6조합 100% 즉시 인식.
- 사진 3장 촬영·저장 완료.
- 대표 5얼룩 실습 재확인(오후 롤플레이 중 1건 포함).

## Day 3 종합 인증
- 3일 통과 기준 전부 충족 → 신입 → 정규 점원 등급 승격.
- 미충족 항목이 있으면 해당 부분만 재교육 후 재시험.
- **미충족 상태에서 매장 단독 접수 금지.**

## 주간 퀴즈 10문항 초안 (Zalo 짧은 답용)
**형식:** 매주 월요일 오전 발송. 4지선다 또는 단답형. 정답률 매장별 집계.
### 세트 1 — 기초·안전 (Day 1 복습)
1. 피 얼룩 세탁 시 수온은? (a) 찬물 15–20°C (b) 미온 30–35°C (c) 온수 40–50°C (d) 고온 60°C 이상
   **정답: (a).** 온수는 단백질을 익혀 갈색 영구 고정.
2. 락스와 절대 혼합 금지인 것 3개는?
   **정답:** 식초·암모니아·산소표백제. 유독 가스 또는 반응 상실.
3. 구석 테스트가 필요한 약품 5종은?
   **정답:** 알코올·아세톤·용제·산소표백·옥살산.
4. 문지름 대신 무엇을 하는가?
   **정답:** 찍어 바름(블롯) — 흰 면 천으로 수직으로 눌러 흡수, 매번 새 면.
5. 건조기·다림질·햇빛 전에 무엇을 확인하는가?
   **정답:** 강광 확인. 잔색·미끄러움·냄새 있으면 열 처리 금지.
### 세트 2 — 얼룩·도구·조달 (Day 2 복습)
6. 흰 식초 1:4를 200ml 분무기로 만들려면?
   **정답:** 식초 40ml + 물 160ml.
7. 실크·울에 효소를 쓰면 안 되는 이유는?
   **정답:** 원단이 단백질이라 효소가 원단 자체를 분해.
8. 볼펜 얼룩에 쓰는 알코올 종류는?
   **정답:** 70% 이소프로판올(약국 소독용). 무수 알코올·에탄올 95%·메탄올 금지.
9. 식용유 처리 순서는?
   **정답:** 흡수 → 전분 흡착 10–30분 → 주방세제 미온 → 미끄러움 확인 → 세탁.
10. 산소표백제(과탄산나트륨) 침지 온도·시간 상한은?
    **정답:** 미온(30–35°C), 15분–2시간. 구석 테스트 필수. 흰 면·색 안정 유색만.
### 세트 3 — 접수·거절 (Day 3 복습)
11. 접수 사진 3장의 대상은?
    **정답:** ① 라벨 근접 ② 얼룩 근접 ③ 옷 전체·색상.
12. 등급 2와 등급 3의 차이는?
    **정답:** 등급 2 = 부분 제거 시도 가능(동의 필요, 잔색 배상 대상 아님). 등급 3 = 복원 불가(전문 의뢰 또는 접수 반려).
13. 거절 게이트 6조합 중 3개를 말하세요.
    **정답 예시:** (1) 실크·울·가죽·아세테이트 + 유성 페인트/유성 매직/502 (2) 건조기 지난 이염 (3) 성분 미상 화학. (나머지: 원단 침투 오래된 곰팡이, 실크·울에 흡수된 엔진오일·타르, 가죽·스웨이드·모피의 용제 얼룩.)
14. 실크·울·가죽·아세테이트 원단이면 자동으로 어떻게 되는가?
    **정답:** 한 단계 상향(L1→L2, L2→L3).
15. 초보 점원이 배상 금액을 즉석에서 확약해도 되는가?
    **정답:** 아니오. "확인 후 안내드리겠습니다"로 응답 → 매장 매니저 상급 보고.
### 세트 4 — 베트남 특화·실전
16. 라테라이트(붉은 적토)를 젖은 채 문지르면?
    **정답:** 심부 침투 → 사실상 복원 불가. 완전 건조 후 실외 털기부터.
17. 라테라이트에 락스를 쓰면?
    **정답:** 철이 영구 고정. 절대 금지.
18. 김치국이 유색 옷에 묻었을 때 산소표백 사용?
    **정답:** 원칙 금지. 고춧가루 색소가 빠질 때 원단 색도 함께 빠짐. 흰옷만 조건부 사용.
19. 오토바이 오일이 실크에 흡수됐다면?
    **정답:** 즉시 전문 의뢰(L3). 매장 자체 시도 금지.
20. 느억맘(액젓) 얼룩 처리 후 냄새가 남으면?
    **정답:** 등급 2 사전 고지. 흰 식초 1:4 반복. 냄새 잔존 가능 명시.
### 퀴즈 운영 방식
- **매주 월요일 오전 9시 Zalo 발송** — 10문항, 응답 마감 화요일 오후 6시.
- **매장별 정답률 집계** — 매주 수요일 매장 매니저에게 리포트.
- **정답률 70% 미만 매장** — 다음 주 오프라인 재교육 1시간.
- **문항 로테이션** — 4세트 × 5주 사이클 + 신규 얼룩·최근 실패 얼룩 추가.
