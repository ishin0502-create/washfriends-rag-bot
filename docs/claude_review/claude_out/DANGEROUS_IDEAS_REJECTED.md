# DANGEROUS_IDEAS_REJECTED — 넣고 싶어도 안 되는 팁
**원칙:** 유튜브·블로그·SNS에 자주 등장하지만 화학·물성 근거로 위험하거나, 잘 되는 것처럼 보여도 원단·안전·법적 위험이 큰 아이디어. 시드·라이브 답·교육 자료 어디에도 넣지 않는다. 팀 온보딩·유튜브 팁 검토 게이트로 상시 참조.
---
## 1. 민간요법 (근거 없음 또는 얼룩 악화)
### 1-1. 치약을 얼룩에 문질러 빼기 — 금지
- **왜 위험:** 대부분 치약에 연마제(실리카·탄산칼슘), 향, 색소, 계면활성이 섞여 있음. 색소 있는 치약은 오히려 얼룩을 추가. 연마제로 문지르면 원단 표면 손상·기모 파괴.
- **대체:** 얼룩 계열에 맞는 표준 SOP(효소·주방세제·흰 식초·산소) 순서.
### 1-2. 콘택트렌즈 세척액으로 단백질 얼룩 제거 — 금지
- **왜 위험:** 렌즈 세척액의 계면활성은 눈 안전 기준으로 매우 약함. 세탁 얼룩엔 효과 미미. 붕산·티메로살 등 성분이 원단·피부에 잔류.
- **대체:** 효소(액체 효소세제) 찬물 침지.
### 1-3. 무즙·과일즙·양파즙으로 얼룩 문지르기 — 금지
- **왜 위험:** 과일즙·야채즙 자체가 탄닌·색소·당분을 추가. 잔당은 마른 뒤 황변 → 새 얼룩 발생. 효소 활성도 표준화 안 됨.
- **대체:** 시판 효소세제(성분표에 enzyme·protease 표기).
### 1-4. 콜라로 기름·녹·핏자국 세탁 — 금지
- **왜 위험:** 콜라의 인산은 세척 효과 미약. 캐러멜 색소·당분 잔여로 얼룩 확대·황변. 마른 뒤 끈적임과 곤충 유인.
- **대체:** 얼룩별 표준 SOP(오일 = 흡착+주방세제, 녹 = 옥살산, 피 = 찬물+효소).
### 1-5. 소금 대량으로 색소 얼룩 빼기 — 부분 허용
- **허용 범위:** 신선한 레드와인·피에 흡수 목적으로 뿌리는 것은 안전(SOP 명시).
- **금지 범위:** 마른 얼룩에 소금 문지르기, 유색에 대량 소금물 침지(색상 손상 가능). 소금이 얼룩을 "빼는" 것이 아니라 "흡수"하는 것임을 혼동 금지.

## 2. 화학 오남용 (원단·안전·색상 파괴)
### 2-1. 베이킹소다 + 식초 거품쇼로 얼룩 빼기 — 금지
- **왜 위험:** 아세트산과 탄산수소나트륨이 만나면 즉시 중화되어 이산화탄소 거품 + 물 + 아세트산나트륨만 남음. **세척력 상실.** 시각적으로만 화려. 잔여물이 원단에 남아 재세탁 필요.
- **대체:** 둘을 순서대로 별도 사용(예: 베이킹소다 페이스트로 흡수·중화 → 헹굼 → 다음 단계에서 흰 식초 1:4).
### 2-2. 뜨거운 물로 모든 얼룩 세탁 — 금지
- **왜 위험:** 단백질(피·계란·우유·땀·구토·분변·소변·모유·정자·분유)은 40°C 이상에서 변성 → **갈색 영구 고착**. 색소(커피·와인·간장·잉크)는 온수·고온에서 원단 결합 강화. 실크·울은 수축·펠팅.
- **대체:** 4단계 수온 표준(찬물/미온/온수/고온) — 단백질·색소는 무조건 찬물부터.
### 2-3. 락스(염소표백) 만능 사용 — 금지
- **왜 위험:**
  - 유색·실크·울·나일론·스판덱스·아세테이트: 색·원단 손상.
  - 데오·땀 황변·분유·선크림: 황변 또는 주황 영구 고착(단백질·아연·철과 반응).
  - 이염 얼룩 유색: 색소 함께 파괴.
  - 오래된 얼룩·냄새 만능 해결책 아님.
- **대체:** 표준 SOP대로 효소·산소·식초·용제 각 계열에 맞게 사용. 락스는 흰 100% 면·폴리에스터·색 없는 옷에만.
### 2-4. 락스 원액을 얼룩에 직접 도포 — 금지
- **왜 위험:** 국소 원단 섬유 산화·구멍 발생. 흰옷도 얇은 옷·구멍 위험. 실외 옷 색빠짐 얼룩화.
- **대체:** 락스는 반드시 희석(물 4L + 락스 큰술 1, 5–15분 상한)해서 침지, 즉시 완전 헹굼.
### 2-5. 락스 + 식초 / 락스 + 암모니아 / 락스 + 산소표백 혼합 — 금지 (안전 위반)
- **왜 위험:**
  - 락스 + 식초/산 = 염소 가스(눈·기도·폐 손상, 밀폐공간 치명).
  - 락스 + 암모니아(암모니아수·일부 유리세정제·오래된 소변 잔여) = 클로라민 가스(폐 손상).
  - 락스 + 산소표백제 = 반응 무력화 + 발열·튐 위험.
- **대체:** 계열 하나만 사용, 통·솔 완전 헹군 뒤에만 다음 약품 접촉.
### 2-6. 과산화수소 원액(30% 이상)을 옷에 사용 — 금지
- **왜 위험:** 30% 이상은 산업용·공업용. 원단 산화·구멍·화상 위험. 눈 튐 시 실명 위험.
- **대체:** 약국 창상소독액 3%(흰 면만, 원액 5–10분 블롯, 구석 테스트). 분말은 과탄산나트륨(마트·워시프렌즈 공급).

## 3. 유튜브·SNS 유행 팁 중 위험 (근거 부족 또는 조건 왜곡)
### 3-1. 아스피린을 갈아 흰옷 황변 제거 — 금지
- **왜 위험:** 아세틸살리실산은 강한 표백 성분 아님. 대량 사용 시 원단 pH 이상·잔여물·황변 도리어 심화. 화학 근거 약함.
- **대체:** 효소 침지 → 흰옷만 과탄산나트륨 산소표백 장침지(테스트).
### 3-2. 구연산을 만능 표백처럼 사용 — 조건부
- **허용 범위:** 경수 지역 광물 침착·다림질 판 물때 제거 등 좁은 목적.
- **금지 범위:** 색소·단백질·유성 얼룩에 구연산 도포하는 것은 효과 없거나 미약. 실크·울에 강한 산 반복 사용은 원단 손상.
### 3-3. 은수저·알루미늄 호일 + 소금물로 이염 제거 — 금지
- **왜 위험:** 갈바닉 반응은 금속 산화물에 한정. 세탁 이염(유기 색소)에 유효 근거 없음. 알루미늄 이온이 옷에 잔류·황변 유발 가능.
- **대체:** 이염 대응 표준 SOP — 즉시 분리·건조 금지·산소 장침지(허용 원단).
### 3-4. 헤어스프레이로 볼펜 얼룩 제거 — 조건부·주의
- **왜:** 과거 알코올 함량이 높던 제품에선 어느 정도 효과 있었음. 현재 제품은 오일·왁스·향료가 늘어 오히려 새 얼룩 유발.
- **대체:** 70% 이소프로판올(약국 소독용) 표준 사용.
### 3-5. 세탁기 온수 최고온 + 얼룩옷 넣고 돌리기 — 금지
- **왜 위험:** 단백질 갈색 고착, 색소 영구화, 실크·울 파괴, 이염 확산. "세탁기가 알아서 해준다"는 잘못된 신뢰.
- **대체:** 얼룩 부분 처리 완료 후에 원단·색상 허용 온도로 본 세탁.
### 3-6. 다림질로 얼룩을 "감춰서" 마무리 — 금지 (클레임 확대)
- **왜 위험:** 열이 얼룩·기름·색소를 원단에 영구 고정. 이후 재처리 불가. 고객이 다림질 후 얼룩 발견 시 매장 과실.
- **대체:** 건조 전 강광 확인 → 잔여 시 반드시 재처리 또는 등급 재고지.

## 4. 원단·도구 파괴 위험
### 4-1. 뻣뻣한 강모 솔·철사 솔·구두솔 사용 — 금지
- **왜 위험:** 원단 기모 파괴·구멍·보풀. 특히 실크·울·니트·기능성 원단.
- **대체:** 아기 칫솔 또는 세탁 전용 부드러운 솔.
### 4-2. 얼룩 옷 전체를 담금통에 침수 — 조건부
- **금지 범위:** 유색 옷 전체 침지 — 다른 부위로 이염·색빠짐.
- **허용 범위:** 얕은 담금통에 얼룩 부위만 잠기게, 원단·색 안정성 확인 후.
### 4-3. 세탁기 최고 회전(고속 탈수)으로 얼룩옷 강제 세탁 — 조건부
- **금지 범위:** 실크·울·기능성·다운·니트에 고속 탈수 — 원단 손상.
- **대체:** 원단 라벨의 허용 회전수, 얼룩 부위 부분 처리 후 본 세탁.
### 4-4. 마른 페인트·풀·잉크를 손톱으로 긁기 — 조건부
- **금지 범위:** 원단 결·기모·프린트를 함께 뜯음. 특히 실크·아세테이트·프린트 티셔츠.
- **대체:** 원단 위 각도를 낮춰(45°) 부드러운 솔 또는 무딘 카드 모서리로 표면만 제거.

### 5-1. 고객 옷의 상표·정품 태그를 임의 제거 — 금지 (법·클레임)
### 5-2. 얼룩 없는 부위에 임의로 산소·염소 침지 — 금지 (매장 과실)
### 5-3. 원단·색상 라벨 확인 없이 강한 약품 시도 — 금지 (배상)
### 5-4. 배상 확약을 접수 담당자가 즉석에서 하는 것 — 금지 (상급 판단 필수)

## 6. 반려 사유 요약 카드 (팀 게시용)
- **화학 근거 없음** → 반려
- **원단 파괴 위험** → 반려
- **가스·화상·중독 위험** → 반려 (혼합 금지 3쌍)
- **색·황변 영구 고착 위험** → 반려 (락스 오남용·뜨거운 물 만능·다림질 감추기)
- **매장 과실·클레임 확대 위험** → 반려 (라벨 미확인·배상 즉석 확약)
새로운 팁이 유튜브·SNS에서 유입될 때, 위 5가지 게이트를 모두 통과할 때만 SOP·시드 반영을 검토.
정리
4개 파일 모두 정정 반영: Cap = 힘 단계(약하게/중간/강하게(찍어 바름)), 내부코드는 평어 치환, 시판 대체는 성분+구입처 중심, 예시 최대 1개, SOP는 짧은 문장 패치만, Cap→ml 치환표 없음.
다음 스텝 제안: (a) A. 전역 치환 규칙을 ko_stain_education.py에 일괄 반영 → 라이브 스모크 → (b) B. 공통 삽입 문장 라이브러리를 SOP 66개에 조건별 자동 삽입 → (c) C. 우선순위 15개 얼룩 패치 적용 → (d) L1 대표 5얼룩으로 초급 챕터 시드 개시.
필요 시 각 파일 개별 확장(예: C절 얼룩 15 → 30개로 확장, L2 교차표 세분화, VN 특화 L3 세트에 이염·황토·오토바이 오일 사례집 추가) 지시 주시면 이어서 진행합니다.
