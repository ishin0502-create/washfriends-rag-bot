## A. 시급 이슈 (SOP 원천 정정 필요)
### A-1. 힘 단계 표기(Cap1/Cap2/Cap3)가 점주용 경로에 그대로 남음 — [L1 영향]
`02_STAIN_SOP_KO.md`의 `fresh_path_ko`/`dried_path_ko`(=점주 답 원천)에 `Cap1/Cap2/Cap3`가 다수 노출.
- 예: `S_LIPSTICK` "겉 왁스 Cap2 바깥→안 긁기", `S_TAR` "Cap2 긁기", `S_SHOE_POLISH` "용제 안쪽 Cap1+흡수지 반복".
- **정정 방향:** 원천에서 평어로 통일. `Cap1` = "약하게(찍어 바름)", `Cap2` = "중간(찍어 바름 반복)", `Cap3` = "강하게(찍어 바름 여러 회, 여전히 문지름 아님)". 힘 개념이지 부피 개념이 아님을 매 SOP에 상기.
- **주의:** "강하게"도 문지름 아님. 색소·오일·잉크 계열은 어떤 단계에서도 옆으로 문지르면 번짐.
### A-2. 약품 내부코드(D2/E1/A3/X2/S1) 점주 경로 노출 — [L1 영향]
- 극단 사례: `S_SHRIMP_PASTE fresh_path_ko` = "D2→E1→A3→흰/면 산소" — 통째로 내부 코드.
- 일부: `S_CURRY` "실크·울: D2+S1", `S_LATERITE` "옥살산 X2 ~2–3%".
- **정정 방향:** 매 SOP에 아래 평어로 통일.
  - D2 → 주방세제
  - E1 → 효소(액체 효소세제)
  - A3 → 흰 식초 1:4 (5% 식용 식초 1 + 물 4)
  - X2 → 옥살산 2% 수용액
  - S1 → 워시프렌즈 중성세제(본사 공급) 또는 시판 중성 손세탁세제
  - Cap1/2/3 → A-1 참조
### A-3. 원단 안전 가드 위치·문구 불일치 — [L2 영향, L1은 무조건 후퇴]
- `S_BLACK_COFFEE why_ko`는 "실크·울+산소 금지"인데 `fresh_path_ko`엔 실크·울 지시 없음.
- `S_HAIR_DYE`는 `dried_path`에만 "실크/울 신중", `fresh_path`엔 없음.
- `S_FRUIT_JUICE fresh_path`도 실크·울 별도 지시 없이 "산소(흰 우선, 테스트)"만.
- **정정 방향:** 산소·효소·용제·염소·옥살산을 쓰는 모든 SOP의 `fresh_path`·`dried_path` 마지막 앞에 공통 문장 삽입:
  `※ 실크·울·가죽·아세테이트: 이 약품 사용 금지 → 워시프렌즈 중성세제 + 찬물로만. 확신 없으면 전문 의뢰.`
### A-4. 수온 표기 편차 — [L1 필수]
- 미온이 30–35°C(분유)·40–50°C(엔진오일) 등 SOP별 다름.
- **정정 방향:** 커리큘럼과 각 SOP에 4단계 표준을 못박음.
  - 찬물 15–20°C (손 담그면 시원)
  - 미온 30–35°C (손 담그면 따끈)
  - 온수 40–50°C (손 담그면 뜨거움)
  - 고온 60°C 이상 (손 못 담금 — 분변·감염 우려 세탁물의 원단 허용 최고온에서만)
- SOP 문장은 "미온(30–35°C)"처럼 숫자 병기.
### A-5. 도구 이름 편차 — [L1 필수]
- "연질 솔"이 칫솔·세탁솔·페인트솔 중 무엇인지 미명시.
- **정정 방향:** 표준 도구 5종 이름 고정.
  - 흰 면 천/키친타월 (색 있는 천 금지)
  - 200ml 분무기
  - 부드러운 솔 = 아기 칫솔 또는 세탁 전용 부드러운 솔 (강모·철사·구두솔 금지)
  - 얕은 담금통 (얼룩 부위만 잠기게)
  - 주방 타이머 (눈짐작 금지)
## B. 정확성 우려 지점
### B-1. 산소표백 사용 조건 편차 — [L2 결정 지점]
- `S_KIMCHI fresh_path` "유색: 식초 반복, 산소 신중" — "신중"이 애매.
- **정정 방향:** 산소표백은 **흰 면·폴리에스터·색상 안정된 유색만**. 색 미확인·실크·울·가죽·나일론·스판덱스는 금지로 명문화. 유색 김치국(고춧가루 색소)에는 원칙 금지 — 산소가 색소를 뺄 때 원단 색도 함께 뺌.
### B-2. 옥살산 침지 시간 상한 — [L3 전용]
- `S_LATERITE fresh_path` "X2 ~2–3% ~30분" — 상한이 강한 원단이라도 부담.
- **정정 방향:** 15분부터 시작, 최대 30분, 즉시 헹굼+베이킹소다 약희석 중화(중화 없이 방치 시 셀룰로스 손상 누적). 실크·울·가죽 절대 금지 재확인.
### B-3. 알코올 종류 통일 — [L1 필수]
- 일부 SOP만 "70% 알코올"·"이소프로필" 명시, 나머지는 "알코올"로만.
- **정정 방향:** 매 사용처를 "70% 이소프로판올(약국 소독용 알코올)"로 통일. 무수 알코올·에탄올 95%·메탄올 금지(원단 손상·독성).
### B-4. 시아노아크릴레이트(502) 접착제 톤 강화 — [L3/거절]
- `S_GLUE dried_path` "종류별 용제·시간"으로만 서술.
- **정정 방향:** 의류에 굳은 502는 대부분 원단 손상 없이 제거 불가. `dried_path` 서두에 "접수 시 100% 불가 고지 → 전문 의뢰 또는 거절 우선 검토" 문장 추가.
### B-5. 유색 이염(dye transfer) 락스 톤 — [L2]
- `S_DYE_TRANSFER fresh_path` "흰 면만 희석 락스(안전할 때)" — "안전할 때"가 모호.
- **정정 방향:** "안전 조건 = 흰 100% 면·폴리 단독, 색 없는 흰옷만, 원단 손상 없이 5–10분 상한, 즉시 완전 헹굼. 스판덱스 혼방·유색·실크·울·나일론은 절대 금지" 명시.
## C. 라이브 답(04) 초보자 이해도 갭
- **1번 블랙커피**: "분무기 라벨" 언급 있으나 초보에겐 병 준비법 없음 → 200ml 분무기에 식초 40ml + 물 160ml 예시 추가 권장.
- **2번 피**: PPE 좋음. 그러나 "부드럽게(흡수·찍기만)" 옆에 "세게 문지르기 금지, 온수 절대 금지" 이유(단백질 변성 = 갈색 영구) 한 줄 반복 삽입 권장.
- **3번 레드와인**: 흰옷 산소 사용 조건 명확. 유색 경우의 "구석 테스트 후에도 색빠짐 있으면 산소 중단" 후퇴 문구 추가 권장.
- **4번 김치**: "찍어 바름"과 "부드러운 솔" 병용 시 어떤 순서인지 불명확 → "세제 도포 = 찍어 바름 → 30초 대기 → 부드러운 솔 가볍게 → 즉시 헹굼" 순서 명시.
## D. 성공률·거절 고지 3단계 표준어 부재 — [L1 접수 필수]
현행: "성공률↓"·"100% 비보장"·"잔영 가능" 표현 혼재.
**정정 방향 — 접수 단계에서 이 3단어만 사용:**
- 등급 1 "시도": 성공 가능 높음, 그래도 완전 제거 보장 없음.
- 등급 2 "부분 제거": 완전 제거 어려움, 잔색·잔영 남을 가능성 큼, 사전 동의 필요.
- 등급 3 "복원 불가": 접수 거절 또는 전문 의뢰. 사진·동의서 필수.
