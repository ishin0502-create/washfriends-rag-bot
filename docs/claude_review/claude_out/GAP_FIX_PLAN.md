# GAP_FIX_PLAN — 초보 재현성·거버넌스 로드맵 (2주 / 4주 / 8주)
**목적:** "완전 초보 점주가 Zalo AI 답만으로 배상 사고 없이 재현" 목표에 가장 빠르게 근접하기 위한 실행 로드맵.
**전제:** 지식·화학은 유지. 전달·거버넌스만 메운다.
**측정 지표(권장):** 매장당 월 배상 사고 건수, 등급 3 얼룩 접수 시 거절/전문 의뢰 전환율, 신입 3일 온보딩 완료 후 대표 5얼룩 실기 통과율.
---
## Phase 1 — 2주 (즉시 위험 차단)
**목표:** "안 시도해야 할 걸 시도"에서 나오는 배상 사고를 절반으로.
1. **STAIN_LEVEL_TAGS 배포·점주 앱 노출** — 66개 얼룩 L1/L2/L3 태그를 접수 화면·Zalo 답 헤더에 표시. L3는 접수 단계에서 자동으로 등급 3 스크립트 안내.
2. **INTAKE_REFUSE_PROTOCOL 3단 스크립트 배포(KO+VI)** — 매장 카운터 게시, Zalo 복붙 템플릿, 접수 사진 3장 필수화.
3. **L1_REWRITE_SAMPLES 대표 5얼룩 라이브 답 교체** — 지시 톤으로 리라이트한 5얼룩(피·블랙커피·식용유·볼펜·진흙)을 우선 배포. 나머지는 Phase 2.
4. **거절 게이트 6조합 시행** — 실크·울·가죽·아세테이트의 유성 페인트/유성 매직/시아노 502, 건조기 후 이염, 원단 침투 곰팡이, 성분 미상 화학, 실크·울에 흡수된 엔진오일·타르, 가죽·스웨이드·모피 용제 얼룩은 매장 자체 시도 금지 → 상급 확인.
**Phase 1 완료 판단**: L3 얼룩 접수 시 100% 등급 3 스크립트 노출, 대표 5얼룩 Zalo 답이 지시 톤으로 나감, 사진 3장 없이 등급 2·3 얼룩 접수 불가.
---
## Phase 2 — 4주 (초보 재현성 확보)
**목표:** 신입 점주가 대표 얼룩 20종을 감독 없이 재현.
1. **TOOLS_TEMP_BUY_CARDS 매장 배포** — 도구 5종·수온 4단계·조달 카드를 A4 코팅해 매장 작업대에 부착. Zalo 답에서도 "도구·수온·조달" 태그 클릭 시 카드 팝업.
2. **SOP 상위 20개 얼룩 지시 톤 리라이트** — Phase 1의 5얼룩 이후, L1·L2 상위 15개(총 20개) 확장. 66개 전체는 Phase 3.
3. **ONBOARDING_3DAY 파일럿** — 신입 5–10명 대상 3일 온보딩 시범 운영. Day 3 실기 통과율 측정.
4. **주간 퀴즈 10문항 Zalo 배포 시작** — 매주 월요일 오전 발송, 정답률 매장별 집계.
**Phase 2 완료 판단**: 신입 3일 온보딩 후 대표 5얼룩 실기 통과율 80% 이상, 주간 퀴즈 매장 평균 정답률 70% 이상.
---
## Phase 3 — 8주 (거버넌스·데이터 루프)
**목표:** 표준-원천-라이브 3층 동기화 완료, 지속 개선 사이클 가동.
1. **SOP 66개 전체 지시 톤 리라이트 완료** — Phase 2의 20개 이후 나머지 46개.
2. **매장별 얼룩 로그 → 재학습 데이터** — 접수·처리·결과·클레임 여부를 매장 앱에서 로그. 월간 리뷰에서 실패 반복 얼룩 우선 재교육.
3. **월간 재교육 사이클 정착** — 매달 첫째 주 = 실패 얼룩 리뷰, 둘째 주 = 신규 얼룩·베트남 특화, 셋째 주 = 접수·거절 롤플레이, 넷째 주 = 실기 시험·인증 갱신.
4. **매장 인증 등급제 도입 검토** — 신입 → 정규 → 마스터 3단계. 마스터 매장만 등급 3 얼룩 자체 처리 시도 승인.
**Phase 3 완료 판단**: 매장당 월 배상 사고 0.5건 이하 목표선 접근, SOP·라이브 답·매장 게시물 3층 표기 100% 일치.
---
## 위험·의존성
- **매장 앱 개발 자원**: Phase 1의 L3 자동 등급 3 스크립트 노출, Phase 2의 도구 카드 팝업은 앱 UI 변경 필요. 앱 팀 병행 필수.
- **베트남어 검수**: INTAKE_REFUSE_PROTOCOL·ONBOARDING의 VI 문장은 현지 매니저(예: Khanh·Thang·Thoa) 검수 후 배포.
- **본사 공급망**: 워시프렌즈 중성세제·산소표백제·옥살산·니트릴 장갑의 매장 공급이 Phase 1 이전에 안정화돼야 조달 카드가 실제로 작동함.
- **원천 파일 정정**: `ko_stain_education.py`의 내부코드 평어 치환은 이미 진행 방향으로 확정. Phase 1 안에 라이브 스모크 완료 필수.
---

Phase 2 (4주) — **재현성**: 도구/수온/조달 카드·상위 20 얼룩 리라이트·3일 온보딩 파일럿·주간 퀴즈.
Phase 3 (8주) — **거버넌스·루프**: 66개 전체 리라이트·매장 로그·월간 재교육 사이클·인증 등급제.
