# TOOLS_TEMP_BUY_CARDS — 도구·수온·조달 표준 카드
**용도:** 매장 작업대 A4 코팅 부착 + Zalo 답에서 태그 클릭 시 팝업. 초보 점주가 "무엇을 어디서 사와서 어느 상태로 만드는가"를 한 눈에.
**규칙:** 브랜드 나열 금지, 성분+구입처 중심, 예시는 "예:" 하나만.
---
## 1. 도구 5종 표준
| 도구 | 설명 | 구입처 | 금지 |
|---|---|---|---|
| **흰 면 천 / 키친타월** | 블롯·색 확인용 | 매장 상시 비치, 마트 | 색 있는 천 금지(이염) |
| **200ml 분무기** | 식초·희석 약품 도포 | 마트 잡화 코너 | 유색 병 불가(내용물 확인 안 됨) |
| **부드러운 솔** | 국소 문지름 (아기 칫솔 또는 세탁 전용 부드러운 솔) | 마트 세탁 코너·약국 | 강모·철사·구두솔 금지 |
| **얕은 담금통** | 부분 침지용 (플라스틱·유리) | 마트 주방 코너 | 옷 전체 침수 금지(이염) |
| **주방 타이머 또는 스마트폰** | 침지·처리 시간 | 스마트폰 앱으로 대체 가능 | 눈짐작 금지 |
**추가 상비**
- 니트릴 장갑 (약국·마트)
- 마스크 (약국·마트)
- 흡수지 (키친타월 대체 가능)

## 2. 수온 4단계 표준
| 단계 | 온도 | 손 감별 | 용도 |
|---|---|---|---|
| **찬물** | 15–20°C | 손 담그면 시원 | **단백질 얼룩(피·계란·우유·땀·구토·분변·소변) 전부.** 색소 초기 처리. |
| **미온** | 30–35°C | 손 담그면 따끈 | 일반 세탁 표준. 산소표백 침지. 커피·차 잔색 처리. |
| **온수** | 40–50°C | 손 담그면 뜨거움 | 지방·유분 강화 세탁. **단백질 얼룩 남은 상태에서 금지.** |
| **고온** | 60°C 이상 | 손 못 담금 | **원단 허용 최고온에서만.** 분변·감염 우려 세탁물. |
**공통 원칙**
- 온도계 없으면 손등으로 감별.
- 의심되면 **찬물부터.**
- 얼룩이 안 빠진 채 온수·고온 세탁 금지 → **영구 고착.**

## 3. 약품 조달 카드 5종
### 카드 A — 액체 효소세제 (E1)
- **성분:** 프로테아제(단백질 분해 효소) 함유 액체 세탁세제. 성분표에 "enzyme / protease" 표기 확인.
- **용도:** 피·계란·우유·땀·구토 등 단백질 얼룩.
- **금지 원단:** 실크·울(원단이 단백질이라 분해됨) → 워시프렌즈 중성세제로 대체.
- **온도:** 40°C 초과 시 효소 실활 → **미온(30–35°C)까지만.**
- **표준 사용:** 얼룩에 직접 큰술 1을 바르고 15–60분 대기, 또는 담금통에 찬물 1L + 큰술 1로 침지.
- **구입처:** 마트 세탁 코너 / 워시프렌즈 공급.
- **예:** 시판 액체 세탁세제 중 성분표에 enzyme 표기 있는 제품.
### 카드 B — 산소표백제 (분말·액체)
- **성분:** 분말 = 과탄산나트륨(sodium percarbonate). 액체 = 과산화수소(H₂O₂) 3%.
- **용도:** 흰옷·색 안정 유색의 탄닌(커피·차·와인) 잔색, 황변, 냄새.
- **금지 원단:** 색 미확인, 실크·울, 가죽, 나일론, 스판덱스.
- **금지 조합:** 락스와 절대 혼합 금지.
- **온도:** 미온(30–35°C) 침지.
- **표준 사용:**
  - 분말: 미온 1L + 큰술 1(약 15g), 15분–2시간, 구석 테스트 필수.
  - 액체 3%: 흰 면만 원액 5–10분 블롯, 구석 테스트 필수.
- **구입처:** 분말 = 마트 세탁 코너 / 워시프렌즈 공급. 액체 3% = 약국 창상소독액.
- **예:** 마트 세탁 코너의 과탄산나트륨 표기 분말.
### 카드 C — 흰 식초 1:4 (A3)
- **성분:** 5% 아세트산(식용 흰 식초). 사과식초·발사믹 금지(색소 있음).
- **용도:** 탄닌·색소·염기성 얼룩(커피·와인·주스·간장·데오·냄새).
- **금지 원단:** 실크·울에 강한 산 반복 금지 → 1:8로 더 묽게.
- **금지 조합:** 락스와 절대 혼합 금지(염소 가스).
- **온도:** 상온.
- **표준 사용:** 200ml 분무기 = 식초 40ml + 물 160ml. 분무 후 5–15분 대기 → 헹굼.
- **구입처:** 마트 조미료 코너.
- **예:** 5% 표기 식용 흰 식초.
### 카드 D — 70% 이소프로판올 (알코올)
- **성분:** 이소프로판올(IPA) 70%. 무수 알코올·에탄올 95%·메탄올 금지.
- **용도:** 볼펜·색소·립스틱 안쪽 블롯. 국소 소독.
- **금지 원단:** 실크·울·아세테이트·프린트 티셔츠 → 구석 테스트 후 판단, 대부분 후퇴.
- **환기:** 창문 열기 필수.
- **표준 사용:** 흰 면 천에 살짝 묻혀 얼룩 안쪽에서 수직 블롯. 매번 새 천, 매번 새 흡수지. 옷에 직접 붓지 않기.
- **구입처:** 약국 소독용 알코올.
- **예:** 약국 소독용 알코올 70%.
### 카드 E — 옥살산 2% 수용액 (X2, L3 전용)
- **성분:** 옥살산 결정을 물에 녹여 2% 수용액.
- **용도:** 라테라이트(적토)·녹 얼룩. 면·린넨·폴리에서만.
- **금지 원단:** 실크·울·가죽·아세테이트 절대 금지.
- **PPE:** 니트릴 장갑·마스크 필수.
- **표준 사용:** 15분부터 시작, 최대 30분. **즉시 헹굼 + 베이킹소다 약희석으로 중화.** 중화 없이 방치 시 셀룰로스 손상.
- **구입처:** 약국(취급 시)·화공약품점 / 워시프렌즈 공급.
- **예:** 워시프렌즈 공급 옥살산 결정.

## 5. 접수 카운터 요약 카드 (A4 게시용)
```
[도구] 흰 면 천 · 200ml 분무기 · 부드러운 솔 · 얕은 담금통 · 타이머
[수온] 찬물 15–20 · 미온 30–35 · 온수 40–50 · 고온 60+ (원단 허용 시)
[힘 단계] 약하게(찍어 바름) / 중간(반복) / 강하게(여러 회) — 옆으로 문지름 금지
[분무기 준비] 흰 식초 1:4 = 식초 40ml + 물 160ml (200ml 병)
[혼합 절대 금지]
락스 + 식초 = 염소 가스
락스 + 암모니아 = 클로라민 가스
락스 + 산소표백 = 반응 상실
[구석 테스트 필수 약품]
알코올 · 아세톤 · 용제 · 산소표백 · 옥살산 → 30초 테스트 없이 사용 금지
