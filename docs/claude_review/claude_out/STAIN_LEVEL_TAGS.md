# STAIN_LEVEL_TAGS — 66 얼룩 L1/L2/L3 태그표
**태그 정의**
- **L1 초보 단독**: 신입 점주가 상급 확인 없이 시도 가능. 대표 오차·손상 위험 낮음.
- **L2 감독 필요**: 원단·색·신선/마름 판단 갈림. 신입은 매장 매니저(또는 6개월 이상 경력자) 확인 후 진행.
- **L3 전문 의뢰·거절 우선**: 초보 단독 시 사고 확률 높음. 접수 단계에서 등급 3 스크립트 우선. 매장 시도는 마스터급만.
**공통 규칙**
- 어떤 얼룩이든 원단이 **실크·울·가죽·아세테이트·모피**면 자동 한 단계 상향(L1→L2, L2→L3).
- 어떤 얼룩이든 이미 **건조기·다림질 지난 후**면 자동 한 단계 상향.
- **성분 미상 화학 얼룩**은 무조건 L3.

## 자동 상향 규칙 (재확인)
- 원단이 **실크·울·가죽·아세테이트·모피** → L1이라도 L2로, L2라도 L3로.
- **이미 건조기·다림질 지남** → 한 단계 상향.
- **성분 미상 화학** → 무조건 L3.
- **500ml 이상 대량·전체 침범** → 한 단계 상향(부분 처리 범위 초과).
- **고객 사진에서 라벨 확인 불가** → 최소 L2 이상으로 접수.
