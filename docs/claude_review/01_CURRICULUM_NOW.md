# 현재 교육 커리큘럼 상태 (As-Is)

이 문서는 “지금 Wash Friends AI가 이미 가르치고 있는 것”과 “아직 약한 것”을 정리한다.  
Claude는 여기를 보고 **초·중·고급으로 재배치·보강**하면 된다.

## A. 이미 강한 축

### A1. 오염 그룹 (화학 분류)

| 그룹 | 대표 | 핵심 원칙 (이미 시드됨) |
|------|------|-------------------------|
| 단백질 | 피, 계란, 우유, 땀, 구토 | 찬물·열 금지, 효소 |
| 탄닌 | 커피, 차, 와인, 주스 | 즉시·찬물, 식초 1:4, 흰옷 산소 |
| 오일/지방 | 식용유, 그리즈, 마요, 버터 | 흡착→주방세제→(리파아제) |
| 색소/염료 | 잉크, 이염, 립스틱 | 블롯, 문지르기 금지, 열 고착 |
| 특수 | 녹, 라테라이트, 곰팡이, 유성페인트 | PPE, 특정 약, 전문 의 |

한국어 교육 경로: `ko_stain_education.py`에 **약 60개** 얼룩 ID (`02_STAIN_SOP_KO.md`).

### A2. 답변 6요소 + 감각/성공률/거절

라이브 프롬프트가 (1)~(6) + why/sense/success/refuse 구조를 강제한다.

### A3. 안전 가드 (일부)

- 실크·울: 효소/산소 차단 방향  
- 가죽·스웨이드: 별도 care 경로  
- 색 미확인: 산소·염소 표백 생략  
- 식초 희석: 점주용 「식초 1 : 물 4」  
- 구매처: 슈퍼/마트/약국/본사 공급 (코드 대신 상품 언어)

### A4. 운영(ops) 일부

접수 스크립트, 클레임, 분류, 경수, 케어라벨 등 ops 노드가 있음 (`education_ops_depth_v12`, `ops_gold` KB).  
다만 **얼룩 SOP만큼 초보자가 “처음부터 따라 하기” 쉬운 형태는 아님**.

## C. 약한 축 (초·중·고급 설계에 꼭 보강)

### C1. 초급 “기초 과목”이 분리되어 있지 않음

점주가 얼룩을 묻기 전에 배워야 할 것:

- 섬유 식별(면/폴리/실크/울/가죽) 30초 방법  
- 찬물 vs 미온 vs 온수 — 언제 쓰면 망하는지  
- 문지르기 vs 찍어 흡수(블롯)  
- 건조기·다리미 = 열고착  
- 구석 테스트  
- 장갑·환기 (피·곰팡이·용제)

→ 지금은 **얼룩 Q&A에 섞여** 나와서, 완전 초보자가 “기초만” 배우기 어렵다.

### C2. 중급 “교차 판단” 연습 부족

- 같은 커피라도: 흰 면 / 유색 / 실크 / 넥타이  
- 같은 피라도: 신선 / 마름 / 이미 온수 세탁 후  
- 표백: 흰옷만 / 색 미확인 생략 / 검정 금지

### C3. 고급 “실패·거절·특수 품목”

- 1차 실패 → 2차 (dried) → 전문/배상 고지  
- 가죽·스웨이드·모피·정장·다운·골프/기능성 — 경로 있으나 **교육 순서도로 정리 안 됨**  
- 접수 사진·동의·100% 불가 고지

### C4. 레벨 표기가 없음

AI가 “이건 초급 필수 / 중급 응용”을 구분하지 않는다.  
Claude 보강 시 **각 개념에 L1/L2/L3 태그**를 달아 달라고 요청한다 (`05_ASK_CLAUDE.md`).

## D. 최근 품질 이슈 (이미 고친 것 — 되살리지 말 것)

| 이슈 | 교훈 |
|------|------|
| `블랙커피 얼룩` → 피로 오탐 | `피 얼룩` 부분문자열이 `커피 얼룩`에 매칭됨 → 수정됨 |
| 신선인데 `1차 실패`/`dried_path` 노출 | 점주 답에 내부 필드명·과도한 rescue 금지 |
| `얇음으로` Cap 단정 | 두께 미확인 ≠ 얇음 |
| 김치 `문지름` vs `문지르기 금지` | 기름 단계는 “찍어 바름”, 세게 문지르기 금지 |
| 산소표백 | 흰옷·원단 허용·구석 테스트 / 색 미확인 시 생략 |

## E. 권장 커리큘럼 뼈대 (Claude가 채울 것)

```
L1 기초 (매일)
  섬유·온도·힘·건조 전 확인·테스트·PPE
  대표 5얼룩: 피 / 커피 / 식용유 / 잉크 / 흙

L2 현장 (주간)
  탄닌 세트 / 단백질 세트 / 오일 세트
  흰·유색·실크 가드
  신선 vs 마름

L3 마스터 (월간)
  실패 2차·거절·클레임
  가죽·정장·다운·VN 특화
  케어라벨·이염·황변
```
