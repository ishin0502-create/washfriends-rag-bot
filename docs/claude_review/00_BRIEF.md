**목적:** Zalo AI 답변만으로 **세탁 초보자도 현장 작업이 가능**하고, 중급·고급은 더 깊은 판단까지 배우게 한다.

## 1. Claude에게 부탁하는 일

1. 이 패키지(`docs/claude_review/`)를 **유일한 기준 자료**로 읽고 검토한다.
2. 교육을 **초급 / 중급 / 고급**으로 나누어, 빠진 개념·순서·감각 체크·실패 대응을 보강한다.
3. 보강안은 **MD로 제안**한다. (바로 코드/시드에 넣지 말 것 — Wash Friends 팀이 검증 후 반영)
4. **풍부함보다 정확성**이 우선이다. 근거 없는 민간요법·브랜드 날조·잘못된 화학 순서를 넣지 말 것.

## 2. 교육이 가야 할 모습

| 레벨 | 점주가 할 수 있어야 하는 것 | 답변에 꼭 있어야 하는 것 |
|------|------------------------------|---------------------------|
| **초급** | 오염 종류 구분, 찬물/온수 판단, 문지르지 않기, 건조 전 확인 | (1)~(6) 짧은 SOP, 살 곳(슈퍼/마트), 희석비, “하지 말 것” |
| **중급** | 원단×색×두께×신선/마름 교차, 표백 여부, 실크·울 금지 | color_note, 산소는 흰옷만, 원단 가드, 성공률 고지 |
| **고급** | 1차 실패 후 2차, 거절·전문 의뢰, 접수/클레임, 가죽·특수 품목 | rescue, 100% 약속 금지, 특수 아이템 경로 |

답변 뼈대(라이브 표준):

1. 오염·원단·두께·색상  
2. 도구 (이름 + 사용법)  
3. 힘·방향 (평어: 약하게 / 찍어 바름 — Cap1 같은 내부코드 금지)  
4. 약품 (제품명·구매처·희석·시간)  
5. 수온  
6. 후관리 (건조 전 강광, 열고착)

보조 블록: `[왜 이 순서]` `[감각 체크]` `[성공률·고지]` `[거절·보내기]`

## 3. 절대 규칙 (위반 제안 금지)

- **내부 코드 노출 금지:** A3, B1, E1, Cap1, PPE, dried_path, S_* id 등을 점주 답에 쓰지 말 것. (내부 문서에서만 ID 사용 OK)
- **민간요법 금지:** 치약, 렌즈액, 무즙, 임의 칵테일 혼합 등
- **화학 순서 날조 금지:** 기존 why/fresh/dried에 없는 약·분·순서를 지어내지 말 것. 바꾸려면 “변경 제안 + 이유”로만.
- **혼합 금지 고지 유지:** 식초+락스(+암모니아) 등
- **실크·울·가죽:** 효소/산소/강한 산·용제 기본 비권장 유지
- **100% 제거 약속 금지**
- **손님용이 아님** — 점주 현장 교육용 톤 (본사 트레이너가 옆에서 지시하는 느낌)
- **출처 URL을 손님/점주 답에 넣지 말 것** (내부 참고만)

## 4. 시스템 사실 (검토 시 참고)

- 라이브 답의 본체는 **Neo4j GraphRAG 시드** + `protocol.py` + `ko_stain_education.py`
- `kb/*.md`는 풍부한 원문·교육 백업 (전부 매 답에 실리지는 않음)
- 언어: 한국어·베트남어 점주 중심 (EN은 보조)
- 최근 수정 포인트: 커피≠피 오탐 수정, 탄닌 산소표백(흰옷만), 김치 문지름→찍어 바름

## 5. 산출물 형식 (Claude가 돌려줄 것)

1. `REVIEW_FINDINGS.md` — 정확성 이슈 / 빠진 초급 개념 / 중·고급 공백  
2. `CURRICULUM_L1_L2_L3.md` — 초·중·고급 커리큘럼 초안  
3. `SOP_PATCH_PROPOSALS.md` — 얼룩별 보강 문장 (기존 why/fresh/dried에 **덧붙일 문장만**, 전면 재작성 최소화)  
4. `DANGEROUS_IDEAS_REJECTED.md` — 넣고 싶어도 안 되는 팁 목록  

화학을 바꿀 때는 반드시: **왜 / 어떤 원단에서 / 흰·유색 / 신선·마름**을 명시.
