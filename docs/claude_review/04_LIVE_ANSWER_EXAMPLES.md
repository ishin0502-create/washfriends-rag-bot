# 라이브 답변 샘플 (점주가 실제로 받는 형태)

출처: 프로덕션 `/ask` 스모크 (2026-08-12, build v18~v19).  
Claude는 이 톤·길이를 **목표 품질**로 보고, 초보자가 막히는 문장을 짚어라.

내부 코드가 섞이면 안 된다. 아래는 이미 점주용으로 다듬힌 답이다.

---

## 1) 블랙커피 (면 티셔츠, 신선) — PASS

질문: `면 티셔츠에 방금 쏟은 블랙커피 얼룩 어떻게 빼?`

```
(1) 오염·원단·두께·색상
블랙커피·얼룩·면·보통 두께·확인. 탄닌 성분 있음.

(2) 도구
흰 천·흡수지: 탄닌·색소 + 보통 두께 면: 바깥→안 찍어 흡수(블롯). …
분무기: 흰 식초(식용 식초 약 5%)를 식초 1 : 물 4로 …
담금통: 5–15분만 담근다.
타이머: 5–15분.

(3) 힘·방향
약하게(흡수·찍기만, 문지르기 금지).

(4) 약품
흰 식초 … 슈퍼/마트 … 식초 1 : 물 4. …
흰/면 잔색: 산소표백.

(5) 수온: 찬물로 헹굼.
(6) 후관리: 건조 전 강광 … 열고착.

[왜 이 순서] 블랙커피=탄닌+갈색 색소 … 찬물→식초 1:4→흰/면 산소.
[감각 체크] 눈: 색 옅어짐. …
[성공률·고지] 즉시·찬물: 높음. 건조 후: 고착 가능.
[거절·보내기] 실크·울+산소·염소 혼합 금지. 100% 보장 거절.
```

**검토 포인트:** 초보자가 “분무기 라벨”을 이해하는지 / 산소표백을 유색에 쓸 위험 고지가 충분한지.

## 2) 피 (피묻은 옷) — PASS (단백질)

질문: `피묻은 옷은 어떻게 세탁하나요?`

```
(1) 신선 핏자국과 보호구(니트릴 장갑·필요시 마스크) …
(2) 도구: 장갑, 마스크, 흰 천, 담금통, 타이머 …
(3) 안쪽 찬물 헹굼 2–3분. 부드럽게(흡수·찍기만).
(4) 소금 … 찬물 1L에 큰술 2, 15–30분.
    효소 … 찬물 1L에 큰술 1, 15–30분. 실크·울금지.
(5) 찬물로 세탁.
(6) 건조 전 강광 … 마른 얼룩이면 열고착 위험.
```

**검토 포인트:** PPE·찬물·소금→효소 순서가 초급에 명확한지 / 온수 금지가 더 강조돼야 하는지.

---

## 3) 레드와인 (흰 면) — PASS (탄닌 + 흰옷 산소)

질문: `흰 면 셔츠에 레드와인 쏟았어 어떻게 빼?`

```
(1) 레드 와인, 탄닌 … 흰색 확인. 흡수·찍기만. …
(2) 흰 천, 분무기 식초 1:4, 담금통 …
(3) 바깥→안 흡수. 문지르기 금지.
(4) 식초 1:4 … 구석 테스트 후 흰색·면 잔색에만 산소표백(15–45분).
(5) 찬물·미온 세탁.
(6) 건조 전 강광 … 잔색 있으면 식초 반복, 건조 금지.
```

**검토 포인트:** 흰옷일 때 산소가 (4)에 들어가고, 색 미확인이면 생략되는 규칙이 커리큘럼에 명시돼 있는지.

---

## 4) 김치국물 (v19) — PASS (기름→식초, 문지름 제거)

질문: `면 티셔츠에 김치국물 묻었어 어떻게 빼?`

```
(1) 김치국물 … 색 미확인 시 약품 보류 → 확인 후 조정.
(2) 흰 천 찍어 흡수 … 연질 솔 … 분무기 흰 식초 …
(3) 약하게(흡수·찍기만, 문지르기 금지).
(4) 주방세제 … 바깥→안 찍어 바름.
    흰 식초 … 식초 1 : 물 4 … 5–10분.
(5) 찬물.
(6) 강광 … 열고착.
※ 흰/면 잔색: 산소표백(색 미확인 시 생략·구석 테스트).
```

**검토 포인트:** 기름(세제)→색소(식초) 이중 층이 초급에게 한 줄로 이해되는지 / “찍어 바름” vs 솔 사용이 헷갈리지 않는지.

## 5) 의도적으로 넣지 않은 나쁜 예시 (되살리지 말 것)

- `블랙커피 얼룩`을 **피 SOP**로 답함 (부분문자열 `피 얼룩` 오탐) → 수정됨
